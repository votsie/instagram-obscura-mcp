Установка Instagram MCP для личного аккаунта

Подключите ИИ-клиент к Instagram: ручной вход через Playwright, работа через Obscura и локальный разбор Reels.

Что понадобится

Нужны Python 3.12 или новее, Google Chrome для окна входа, FFmpeg и ffprobe, aria2c для загрузок при установке и ИИ-клиент с поддержкой MCP. С настоящим движком Obscura проверена Windows x86-64. Для других систем установите совместимый бинарник Obscura отдельно и проверьте его работу.

Для речи нужны дополнительные зависимости analysis и локальная многоязычная модель faster-whisper. Модель занимает около 484 МБ, архив браузера Windows — около 69 МБ. Загрузка выполняется на отдельном шаге установки.

1. Скачайте исходники и создайте окружение

git clone https://github.com/votsie/instagram-obscura-mcp.git
cd instagram-obscura-mcp
python -m venv .venv

Активируйте окружение командой .venv\Scripts\Activate.ps1 в PowerShell или source .venv/bin/activate в Unix. Затем установите пакет:

python -m pip install ".[analysis]"

Пакет устанавливается из исходников. Публикация в PyPI пока не заявляется.

2. Установите движок и модель

instagram-mcp-setup --obscura --model
instagram-mcp-doctor

Флаги --obscura и --model можно запускать по отдельности. Автоустановка браузера рассчитана на Windows x86-64; в других системах задайте путь к установленному совместимому бинарнику в INSTAGRAM_OBSCURA_BINARY. Путь к модели задаётся через INSTAGRAM_WHISPER_MODEL. Выберите многоязычную модель, а не английскую .en.

Установщик проверяет размер и SHA-256 закреплённых файлов. Doctor проверяет локальные зависимости без входа и запросов к Instagram; наличие Chrome он пока не определяет.

3. Подключите MCP к ИИ-клиенту

Укажите абсолютный путь к исполняемому файлу окружения: .venv/Scripts/instagram-mcp.exe в Windows или .venv/bin/instagram-mcp в Unix. Передайте нужные переменные через настройки MCP-клиента.

codex mcp add instagram -- /absolute/path/to/.venv/bin/instagram-mcp

Эта команда предназначена для Codex. Общий пример MCP JSON находится в README; форматы настроек клиентов различаются. Если инструменты не появились, перезапустите клиент.

4. Войдите и проверьте аккаунт

  1. Попросите ИИ вызвать instagram_health и instagram_login_start.
  2. Самостоятельно завершите вход и 2FA в видимом окне Instagram. Не отправляйте пароль и коды в чат.
  3. Вызовите instagram_login_finish, затем instagram_account_info, чтобы проверить сессию в Obscura.
  4. Передайте ссылку на Reel или попросите открыть сохранённое.

После входа обращения к Instagram и CDN идут через Obscura. Сам статус входа не доказывает работоспособность переданной сессии — проверьте результат account_info.

Приватность и неполадки

Профиль, cookies, скачанные медиа и транскрипты остаются в локальном каталоге данных. Защитите этот каталог и не добавляйте его в Git. Загрузка вложений по умолчанию выключена; её включение даёт Obscura более широкий доступ к файлам. Перед включением прочитайте руководство по безопасности.

Отсутствующая модель, недоступное видео, проверка Instagram или несовместимая страница могут остановить конкретную операцию. Следуйте сообщению об ошибке; ошибка распознавания не означает отсутствия речи. Доступность функций Instagram и интерфейс могут измениться.
