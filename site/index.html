Useful answers before you connect.

Does it require a business account?

No. This is a browser-based personal-account workflow, not a Graph API integration.

Does it understand every language?

It uses multilingual Whisper with automatic detection. Coverage and accuracy vary; the host assistant handles explanation, translation and on-screen text.

Can it send messages and publish?

It exposes account-checked UI primitives. Dedicated send/publish APIs are not provided, and real sends/publications were not release-tested. Verify each requested operation.

Is account data public?

The repository contains no sessions, saved-post data or downloaded media. Your local runtime persists private cookies and artifacts; protect it and review the threat model.
