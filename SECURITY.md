# Security policy

Do not post credentials, session cookies, private messages, saved-post lists, screenshots or signed CDN URLs in public issues.
Use the repository's **Security → Report a vulnerability** feature if enabled. If private reporting is unavailable, open a minimal issue requesting a private contact without exploit details or sensitive data.

This project is an experimental local tool. There is no security SLA. See [the threat model](docs/security.md) before connecting a real account.
Only the latest released version is considered for fixes. Do not expose the stdio server or its loopback browser control endpoint to a network.
