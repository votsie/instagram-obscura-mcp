# Changelog

## 0.1.0 — initial public package

- 22 stdio MCP tools for manual login, account reads, saved posts, bounded UI actions and Reel analysis.
- Playwright login followed by Obscura-only Instagram/CDN access.
- Local multilingual speech transcription and sampled video frames.
- English and Russian documentation, agent skill and static project pages.

This is an experimental first release. PyPI and MCP Registry publication are separate from GitHub availability.
