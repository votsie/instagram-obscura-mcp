# Asset provenance and prompts

The README cover was generated with the built-in image_gen tool and inspected for correct lettering. No Instagram account content was used as a reference.

## Hero prompt

Create a polished original open source GitHub README hero banner, landscape 3:1 composition, high quality editorial tech brand design. Project exact name 'Instagram Obscura MCP' and smaller exact tagline 'Reels. Speech. Context.' English typography only, perfectly spelled readable title left, lots of breathing room. Right: a compact original friendly confident geometric symbol combining a video play aperture with three rounded audio waveform bars flowing into a small context spark, independent brand mark, strong silhouette, NOT the Instagram logo. Ink navy background #101923, warm coral #FF705B and mint #8DE0C4 accents, subtle cream #F4F0E7 text. Sophisticated flat vector-like aesthetic with modest soft depth, no generic neon glowing circuitry, no fake interface, no humans, no stock photo, no badges, no browser chrome. A subtle sequence of three thumbnail-shaped abstract panels behind the icon suggests video frames to transcript to understanding. Every shape crisp, restrained and generous. This is a real developer tool identity, no claims about security or official affiliation. Keep all title and symbol elements inside central safe margins. Deliver the completed banner.

## Production files

`hero.png` is the original opaque raster cover. The site's `hero.webp` is a lossless encoding of the same artwork, reducing bytes without a visual redesign. `mark.svg`, `mark-mono.svg` and `flow.svg` are separately hand-authored vectors; they are not claimed to be traced vector versions of the generated artwork. Additional generated icon experiments were not selected for the release because their edges/effects were unsuitable for a small production mark.
