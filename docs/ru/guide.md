# Сценарии, языки и ограничения

[English: languages](../languages.md) · [English: limitations](../limitations.md)

Для Reel вызовите reel_start без language для автоопределения, дождитесь completed через reel_status, прочитайте transcript.txt и manifest.json, просмотрите contact.jpg и нужные frame_NNN.jpg. Транскрипт сохраняется на языке оригинала. Разбор, перевод и чтение экранных надписей выполняет ИИ-клиент; отдельного OCR и переводчика в MCP нет.

Многоязычность не ограничена английским и русским. Можно явно указать поддерживаемый моделью код языка. Покрытие и точность различаются; диалекты, короткие записи, музыка, несколько говорящих и смешение языков могут распознаваться плохо. Автоопределение не гарантирует разметку каждого переключения языка. Не считайте ошибку распознавания отсутствием речи; сверяйте имена и числа.

Для сохранённого проверьте аккаунт, вызовите saved_list и проверьте тип первой публикации через read_post. Список отражает загруженную часть, а не полный экспорт. Порядок сетки сам по себе не доказывает дату сохранения. Для карусели используйте post_image с нужным номером слайда.

Действия: откройте страницу через open, получите свежие refs через snapshot. click/fill/press/upload требуют правильный expected_account. Проверяйте видимый результат; не повторяйте неизвестный результат отправки автоматически.

## Проверенные границы

- Windows проверена с настоящим локальным Obscura. Другие ОС требуют своей проверки совместимости.
- При разработке проверены перенос входа, аккаунт, сохранённое, подпись, карусель и полный Reel с речью и кадрами. В публичных тестах используются синтетические данные.
- Реальные Direct, публикации, подписки, лайки и удаления при выпуске не тестировались. Специальных API для них нет: используются примитивы интерфейса.
- Некоторые операции Instagram отвечали ошибкой GraphQL 1357054. Это возвращается как ограничение, без скрытой подмены движка.
- В Obscura добавлен только отсутствующий тип ServiceWorkerRegistration для проверки возможностей страницы; реальные service workers не имитируются.
- Лимит видео — 200 MiB. Кадры выборочные и могут пропустить короткое событие. Дополнительные кадры можно получить из уже скачанного файла локально.
- Профиль и завершённые результаты сохраняются; автоматической очистки нет.
