# Правила поведения в сообществе

[Полный Code of Conduct на английском](../../CODE_OF_CONDUCT.md) — основной документ, основанный на Contributor Covenant 2.1. Здесь приведено русское пояснение.

Участвуйте уважительно: принимайте конструктивную обратную связь, учитывайте разные точки зрения и потребности, признавайте ошибки и обсуждайте работу, а не личность автора.

Не допускаются травля, угрозы, домогательства, оскорбления, дискриминационные высказывания, нежелательные сексуальные обращения и публикация чужих персональных данных без разрешения.

Правила действуют в issues, pull requests, обсуждениях и других пространствах проекта, а также при официальном представительстве сообщества. Модератор может удалить неприемлемое содержимое, предупредить участника, временно ограничить участие или применить постоянный запрет в зависимости от тяжести и повторяемости нарушения.

О нарушении сообщайте приватно сопровождающему проекта: [aafeklisto@gmail.com](mailto:aafeklisto@gmail.com). Не публикуйте детали инцидента и персональные данные в открытых issues. Если почта недоступна, запросите приватный канал через контактные способы, указанные в [публичном профиле автора](https://github.com/votsie). Личные сведения заявителя должны оставаться конфиденциальными.

Источник и атрибуция: [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Это пояснение не заменяет полный английский документ.
