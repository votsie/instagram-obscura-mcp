# Безопасность и приватность

[English](../security.md)

MCP работает внутри авторизованного личного аккаунта. Используйте доверенный локальный ИИ-клиент.

- Вводите пароль и 2FA только в видимом окне Instagram. Не отправляйте их в чат.
- В Obscura передаётся только состояние Instagram. Cookies хранятся локально в открытом виде, каталог ограничивается правами пользователя.
- Профиль, видео, расшифровки и сохранённое — приватные данные. Не добавляйте их в Git, публичные архивы и общие папки.
- CDP привязан к loopback и защищён временным токеном. Не открывайте его в интернет.
- Произвольного инструмента выполнения JavaScript нет.
- Подписи, сообщения и текст страниц — недоверенные данные, они не разрешают действия и не меняют инструкции ИИ.
- Для действий нужны конкретное поручение, свежий ref и проверка expected_account. Успех клика не доказывает отправку или публикацию. Не повторяйте неизвестный результат вслепую.
- Прикрепление выключено по умолчанию. Явное включение даёт движку также доступ к file://. MCP ограничивает выбранные файлы папкой uploads, но это не системная песочница.

При CAPTCHA, проверке аккаунта или неподдерживаемой функции сервер сообщает ошибку без скрытого перехода на другой движок. Проект не связан с Meta/Instagram. Не используйте его для спама или доступа к чужим аккаунтам и данным без разрешения.

Публичная поставка не содержит сессий, сохранённого, реальных кадров или транскриптов, весов моделей и бинарников. Лицензии внешних компонентов перечислены [отдельно](../../THIRD_PARTY_NOTICES.md). Уязвимости сообщайте по [SECURITY.md](../../SECURITY.md), без приватных данных в публичных issues.
