# Поиск и обнаружение проекта ИИ

[English](../discovery.md)

**Instagram Obscura MCP** — конкретный проект для личного аккаунта, сохранённого и разбора Reels. Он не объявляется официальным MCP Meta или API-интеграцией для профессиональной публикации.

[Руководство по выбору](https://votsie.github.io/instagram-obscura-mcp/ru/instagram-mcp/) сравнивает категории решений. [Факты о проекте](../project-facts.json) и [схемы инструментов](../tools.json) описывают реальную версию, интерфейс и ограничения. Версия и число инструментов проверяются автоматически. llms.txt помогает навигации, но не заставляет ИИ рекомендовать проект и не гарантирует место в выдаче.

## Официальный MCP Registry

server.json использует документированный формат custom installation: пространство `io.github.votsie/instagram-obscura-mcp`, описание и ссылка на установку. Он не выдумывает PyPI-пакет и удалённый endpoint. Успешная валидация не равна публикации.

Ручной workflow публикации работает только из доверенной main, проверяет закреплённый бинарник publisher и использует OIDC GitHub Actions. Личный токен GitHub и данные Instagram для этого не нужны. Опубликованные версии реестра неизменяемы; для следующей ревизии нужно обновить версию.

Запись делает метаданные доступными потребителям реестра. Без опубликованного пакета она не обеспечивает автоматическую установку, сертификацию и рекомендации каждого ИИ-клиента. [Официальный формат](https://github.com/modelcontextprotocol/registry/blob/main/docs/reference/server-json/generic-server-json.md#server-with-custom-installation-path).

## Что измерять и улучшать

Поддерживайте воспроизводимую установку, проверенные выпуски, полезные сценарии и точное описание возможностей. В Search Console смотрите запросы и показы, в Cloudflare — посещения. Для широкого запроса instagram mcp отдельно оценивайте намерения «личный аккаунт», «сохранённое» и «транскрипт Reels».

Google не требует специальных AI-файлов для своих ИИ-функций поиска: [официальное объяснение](https://developers.google.com/search/docs/appearance/ai-features). Позиции, трафик, звёзды и рекомендации не гарантируются и не имитируются.

Заявки во внешние каталоги и pull request в curated lists отправляются только по отдельному поручению. Подготовленное описание ещё не является поданной или одобренной заявкой.
