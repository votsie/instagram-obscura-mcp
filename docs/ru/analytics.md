# Аналитика и измерения

[English](../analytics.md) · [Статистика репозитория GitHub](https://github.com/votsie/instagram-obscura-mcp/graphs/traffic)

## Сайт

Публичный сайт проекта использует [Cloudflare Web Analytics](https://developers.cloudflare.com/web-analytics/) для просмотров, посещений, источников переходов и скорости страниц. Войдите в Cloudflare, откройте **Web Analytics** и выберите сайт `votsie.github.io`. Данные после посещения появляются с задержкой.

Локальный загрузчик подключает официальный beacon Cloudflare только на HTTPS-хосте `votsie.github.io` и путях внутри `/instagram-obscura-mcp/`. На localhost, другом домене, другом проекте GitHub Pages и при включённом Global Privacy Control или Do Not Track счётчик не запускается. Если JavaScript или beacon заблокированы, сайт продолжает работать. Расширения браузера, ошибки сети и настройки приватности могут мешать подсчёту.

Cloudflare сообщает данные страниц, источников и производительности браузера. Согласно Cloudflare, Web Analytics не записывает параметры query, не поддерживает UTM и пользовательские события кликов, а история доступна за предыдущие шесть месяцев. Просмотры страниц нельзя считать кликами по кнопкам или скачиваниями. См. [FAQ Cloudflare](https://developers.cloudflare.com/web-analytics/faq/) и [описание сбора данных](https://developers.cloudflare.com/web-analytics/data-metrics/data-origin-and-collection/).

Beacon сайта не запускается внутри Instagram MCP и не используется для сбора паролей Instagram, cookies, состояния аккаунта, постов, сохранённого или транскриптов Reels. Публичный токен сайта идентифицирует счётчик Cloudflare и не является ключом API.

## Активность GitHub

[Traffic](https://github.com/votsie/instagram-obscura-mcp/graphs/traffic) показывает просмотры, уникальных посетителей, полные клонирования, источники переходов и популярные материалы за последние 14 дней; учитывайте правила и задержку GitHub. Полное клонирование не равно fetch или установке; сумма уникальных посетителей за отдельные дни не равна уникальной аудитории за большой период. Звёзды, форки, issues и pull requests смотрите отдельно на странице репозитория и в Insights.

Автоматического архива истории GitHub в этом репозитории пока нет. Для долговременного хранения нужны отдельное хранилище и ограниченный токен с доступом к traffic API. Не размещайте personal access token и токен входа `gh` в публичных исходниках или отчётах.

## Поисковая выдача

[Google Search Console](https://search.google.com/search-console/) показывает поисковые показы, клики, проиндексированные страницы и состояние sitemap для подтверждённого ресурса. Подтверждение и отправка sitemap выполняются в аккаунте владельца: наличие проверочного файла в исходниках само по себе не доказывает ни подтверждение, ни индексацию. Поисковые метрики и посещения сайта измеряют разные вещи и имеют разную задержку.

При тестировании релиза учитывайте свои тестовые посещения отдельно и не выдавайте их за внешнюю аудиторию. [Инструкция Cloudflare](https://developers.cloudflare.com/web-analytics/get-started/).
